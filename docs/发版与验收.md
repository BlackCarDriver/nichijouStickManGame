# 发版与验收（v3 起）

**前后端协议必须同版本上线**：`curl /healthz` 里的 `gameProtocol` 要等于 `src/net/protocol.ts`
里的 `GAME_PROTOCOL_VERSION`（当前 **5**）。只换前端或只换服务端都会出现"不掉血/捡不到"。

本文件也随发版包附一份（`README-发版说明.md`）。

## 依赖准备（首次/升级 SDK 后）

服务端依赖私有 Go 包 `github.com/BlackCarDriver/nichijouSDK`，构建机需要能拉到它：

```bash
cd server
go env -w GOPRIVATE=github.com/BlackCarDriver/*   # 一次性设置（走 git 而非 proxy）
go mod download                                  # 首次或 SDK 版本变更后
```

升级 SDK：把 `server/go.mod` 的版本号改成新 tag（如 `v0.1.1`）后 `go mod tidy`、重新构建，
重启服务后 `curl /healthz` 里的 `sdk` 字段应变成新版本号。

## 打包（本地）

```bash
npm run build                                  # dist/（含 tsc + 数据校验）
cd server
GOOS=linux GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o ../release/stickman-server-linux-amd64 .
GOOS=linux GOARCH=arm64 go build -trimpath -ldflags="-s -w" -o ../release/stickman-server-linux-arm64 .
```

## 包内容

```
dist/                    前端产物（由 Go 服务同源托管）
stickman-server-linux-amd64   Linux x86_64 静态二进制（绝大多数 ECS 用这个）
stickman-server-linux-arm64   Linux arm64 静态二进制（部分 ECS/倚天实例）
plugin_config.example.json / integration.example.json   配置模板（不要覆盖线上已有的配置）
```

## 部署步骤（阿里云）

```bash
# 1. 停旧服务
sudo systemctl stop stickman        # 或你用的进程管理方式（pm2/supervisor/手动）

# 2. 备份（出问题可一键回滚）
sudo cp -a /opt/stickman/dist          /opt/stickman/dist.bak.$(date +%F-%H%M)
sudo cp -a /opt/stickman/stickman-server /opt/stickman/stickman-server.bak

# 3. 覆盖前端与二进制（integration.json / plugin_config.json 保持不动）
sudo rm -rf /opt/stickman/dist && sudo cp -R dist /opt/stickman/dist
# 按架构选一个（uname -m 看：x86_64 → amd64；aarch64 → arm64）
sudo install -m755 stickman-server-linux-amd64 /opt/stickman/stickman-server

# 4. 起服务
sudo systemctl start stickman

# 5. 确认后端已是新版（必须看到 "gameProtocol":3）
curl -s http://127.0.0.1:8092/healthz
# {"ok":true,"bridge":true,"gameProtocol":3,...}
```

> 反向代理（nginx）无需改动：`/ws` 仍需支持 Upgrade。

## 上线验收（5 分钟）

1. 房间地址后加 `?netdebug=1` 打开诊断面板，两人以上进房：
   - `role` 一方 `authority`、其余 `client`；`host` 数字一致（不一致会在 33ms 内自愈）
   - `ping` 是正常毫秒数（不是十几位数）
   - `pos`/`snap` 都在 15~25Hz，`丢帧` 不持续增长
   - `远端位移` 通常 < 25px/帧（长时间 40+ 说明对手在瞬移）
2. 玩法验收：
   - [ ] 连续跳跃、跑动不出现"被拉回"
   - [ ] 打中对手会掉血（双方血量一致）
   - [ ] 从高处跳下会掉血
   - [ ] 走到枪上能捡起来（空手自动捡，持枪按右键替换）
   - [ ] 打散纸箱堆后，双方看到的箱子位置一致
   - [ ] 击杀后 4 秒才弹结算，且显示"被谁用什么击败"，死亡镜头跟随击败者
   - [ ] 房主退出后，剩余玩家继续能打（世界权威自动顺延）
3. 手机竖屏打开房间页：画面自动横过来铺满（`?netdebug=1` 面板也会跟着转）。

## 出问题时怎么反馈

让对方在游戏里执行（F12 控制台）：

```js
__netDiag()
```

把返回的 JSON 连同"他当时的感受（卡/捡不到/不掉血）"一起发来即可定位。
若整房间"只能看不能打"，看 `role`/`host` 是否出现"所有人都是 client"——
v3 的自愈与看门狗会把它拽回来，若仍复现请把当时 `__netDiag()` 发我。

## 回滚

```bash
sudo systemctl stop stickman
sudo rm -rf /opt/stickman/dist && sudo cp -a /opt/stickman/dist.bak.<时间> /opt/stickman/dist
sudo cp -a /opt/stickman/stickman-server.bak /opt/stickman/stickman-server
sudo systemctl start stickman
```
